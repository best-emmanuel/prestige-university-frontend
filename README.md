# Prestige University — Professional Frontend

This is a polished static frontend foundation intended for GitHub Pages and later Django integration.

## Included
- Professional responsive design system
- Homepage, About, Academics, Admissions, Campus Life, Contact
- 12 faculty landing pages
- Student portal demonstration
- Accessible responsive navigation
- Central CSS and JavaScript
- Self-contained SVG visual assets so there are no broken external image URLs

## Important
The admissions, contact and login functionality is intentionally demo-only. It does not represent secure production authentication or a real university database. The next phase is to connect these interfaces to Django, PostgreSQL, real authentication, media uploads and an administration dashboard.

## GitHub Pages
`index.html` is in the repository root and the project uses relative links, so it is suitable for GitHub Pages.
