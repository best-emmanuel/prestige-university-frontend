# Prestige University Website

Static GitHub Pages website. Upload **all files in this folder to the repository root**.

## Important
- `script.js` is included because several pages depend on it.
- Faculty pages have both the original names (`science.html`, `arts.html`, etc.) and canonical `faculty-*.html` aliases to prevent the earlier 404 path problem.
- `404.html` provides a safe fallback for invalid routes.
- Forms and login are demo front-end functionality using browser storage/session storage; they are not real authentication or a database.

## Pages
Home, About, Faculties, Science, Arts, Engineering, Management, Admissions, Contact, Student Portal, Dashboard.
